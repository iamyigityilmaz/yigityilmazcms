Instagram comment and DM bot

Status: Running on a demo account, being prepared for production

A bot that answers the comments and DMs reaching the clinic's Instagram account. AI only labels the language and category of each message; a fixed decision table settles what happens next.

  • Prices and medical advice are never written; code checks this rule a second time.
  • On complaints and emergencies the bot stays quiet, the team is emailed and a human takes over.
  • Replies in seven languages, in whichever alphabet the person used.
  • Tested against more than 30 scenarios and improved across fifteen versions.
  • n8n
  • Node.js
  • Meta Graph API
  • Groq
  • Gemini

WhatsApp pre-consultation assistant

Status: In development

An assistant that greets first-time WhatsApp contacts in their own language, learns what they need through a short menu and hands the conversation to the team. People are told from the start that they are talking to an AI assistant.

  • The first message opens a CRM card; the same person never gets a second one.
  • The team gets an info email and the first agent to claim the record owns it.
  • If nobody responds within 30 minutes, a reminder goes out.
  • The bot can only open cards and add notes; it cannot delete any record.
  • n8n
  • WhatsApp Cloud API
  • Gemini
  • Bitrix24

Competitor tracking and daily report

Status: Running, new data sources being added

A weekly flow that reads competitors' public Instagram data through Meta's official interface, and a daily report that interprets it. No scraping, only permitted sources.

  • Followers, average likes and comments, engagement rate and weekly post count.
  • Data is written to a Google Sheets table, and the report reads from there.
  • The report first says what changed today, then what could be done about it.
  • n8n
  • Meta Business Discovery
  • Google Sheets
  • Claude
